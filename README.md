# deploy

Lineage generic Helm charts and synthetic fixture data.

Part of [Lineage](https://github.com/line-age/controlplane). What this component takes in,
what it puts out, and what it depends on are described in the controlplane's
[components.md](https://github.com/line-age/controlplane/blob/main/components.md#deploy);
this README will say how it is built once it is.

Charts here are generic and fixtures are synthetic or public. No hostnames, cluster names,
secrets, environment values or the research partner's data; see controlplane decisions
L-0006 and L-0009.

Work is tracked in the [Infrastructure](https://github.com/orgs/line-age/projects/9) project.
The team lead is [@sudosume](https://github.com/sudosume). If that changes, the
[controlplane's table](https://github.com/line-age/controlplane#projects-and-leads) is updated first.
